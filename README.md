# Ubike-usage-crawler
## 摘要
本專案的目的是將臺灣 [Youbike](https://www.youbike.com.tw/region/main/stations/) 公司提供給大眾查詢的數據透過網路爬蟲方式存下大部分站點的車輛數量狀況。
## 資料
資料格式是以duck database 儲存，每90~100Mb被分到一個檔案，但所有資料庫的內容都是相同的，分析時可以直接合併。  
資料記錄頻率大約是每日 63次，自大約 2025-05-01 開始記錄，目前沒有打算中斷。
## 願景
希望能做出一個類似於 google map 的人流預測，能夠預測特定時間 Ubike 的數量，對於規劃未來針對特定地點的行程會非常有幫助。
